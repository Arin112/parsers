# Ficbook → FB2 (Selenium)

Скрипт с минимальным GUI на `tkinter`, который открывает **видимый браузер Chrome через Selenium**, читает главы Ficbook и собирает их в один `FB2`.

## Что умеет

- Поле для URL произведения.
- Выбор папки сохранения.
- Запоминание папки в `settings.ini`.
- Парсинг содержания (`ul.list-of-fanfic-parts`) и каждой главы.
- Пауза **3 секунды** между переходами по главам.
- Логирование (`INFO`, `ERROR`) прямо в окне.
- Если происходит редирект на Cloudflare/капчу, скрипт ждёт ручного решения и продолжает автоматически.
- Используется постоянный профиль Chrome (`chrome_profile`), который сохраняется между запусками.
- Сохранение метаданных в FB2: автор, название, аннотация, язык, URL-источник.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python ficbook_to_fb2.py
```

## Важно

- Браузер не headless: окно Chrome видно во время работы.
- URL автоматически нормализуется (убираются query/fragment).
- Примечания главы добавляются в конец секции главы в FB2.
