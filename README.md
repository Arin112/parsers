# Ficbook → FB2

Минимальный GUI-скрипт на `tkinter` для скачивания глав произведения с Ficbook и сборки в `FB2`.

## Возможности

- Вставка URL произведения.
- Выбор каталога для сохранения.
- Сохранение последней папки в `settings.ini`.
- Парсинг списка глав.
- Пауза 3 секунды между запросами глав.
- Логирование действий (`INFO`, `ERROR`) в окне.
- Запись метаданных FB2 (название, автор, описание, язык, источник, дата генерации).

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python ficbook_to_fb2.py
```

## Важно

- URL вида `https://ficbook.net/readfic/...?...` автоматически нормализуется (без query/fragment).
- Примечания главы добавляются в конец соответствующей секции в FB2.
